# SoundFuchs - Export für den Guided Agent

Generierter Uploadstand: Wissensbasis 2.0, App 2.0.0.

Diese Kopien nicht direkt bearbeiten. Quellen liegen unter `docs/` und im Repository-Stamm. Nach Änderungen zuerst `npm run docs:pdf` und danach `npm run docs:guided-upload` ausführen.

1. Den Inhalt von `guided-agent-systemprompt.txt` in das Anweisungsfeld kopieren.
2. Die vier Markdown-Dateien und die PDF als Wissen hochladen.
3. Testfragen stellen, etwa: „Wie lege ich meinen ersten Normalzustand an?“ und „Lädt SoundFuchs mein Geräusch hoch?“

Die PDF enthält zusätzlich den visuellen Bildanhang. Alle Bilder verwenden ausschließlich Demo- oder synthetische Daten.
